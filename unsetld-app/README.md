# UNSETLD app

A daily discipline app for guys 18–30: lock screen and home screen widgets, a swipe feed, reminders, streaks and a rank system. *Never settle for less. Never stop working.* Showing up earns XP; higher ranks unlock capped UNSETLD perks.
